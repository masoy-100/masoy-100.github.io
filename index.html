Sneaker release monitor and checkout bot

2023 to 2025

Watches retailer endpoints for restocks and new drops, then runs checkout across a pool of proxied sessions before the item sells out. Built for the resale market, where inventory is fixed and speed is the whole game.

  1. monitorpoll product endpoints
  2. detectdiff stock state
  3. sessionsproxy pool, cookies
  4. checkoutparallel tasks
  5. notifyDiscord webhook

Technical decisions

  • Rotating residential proxies with per-session sticky IPs so a cart and its checkout come from the same address. Datacenter IPs got flagged within minutes.
  • Session state (cookies, CSRF tokens, cart IDs) is persisted per task so a crash mid-checkout can resume instead of restarting.
  • Monitor and checkout are separate processes talking over a queue. Polling stays cheap and steady while checkout bursts.
  • Backoff is jittered per proxy, not global, so one rate-limited IP doesn't slow the whole pool.
# one session per task, pinned to one proxy
session = make_session(proxy=pool.lease(sticky=True))
session.headers.update(fingerprint())
resp = session.get(product_url, timeout=4)
if stock_changed(prev, resp.json()):
    queue.put(CheckoutTask(sku, size, session))

Decision support system for coins and precious metals

2026

Pulls live spot prices and dealer listings for gold, silver, and platinum products, works out the real premium over melt value on every listing, and scores each one against a buyer's goals so the decision is "buy this, skip that" instead of a spreadsheet of numbers.

  1. spotmetals price feed
  2. dealersscrape listings
  3. normalizeweight, purity, fees
  4. scoreweighted criteria
  5. recommendranked buy list

Technical decisions

  • Every listing gets reduced to one comparable number first: total landed cost per troy ounce of pure metal, including shipping and payment fees. Dealers list the same coin a dozen ways and premiums hide in the fine print.
  • Spot price is pulled on its own schedule and cached, so a dealer scrape hitting 40 pages doesn't spam the price API.
  • Scoring is a weighted model the user controls: premium over spot, dealer reputation, liquidity, and numismatic upside for graded coins. Change the weights and the ranking updates.
  • Historical premiums are stored so the system can flag when a product is cheap relative to its own average, not just cheap today.
# landed cost per ounce of pure metal, then score
oz_pure = item.weight_oz * item.purity
landed  = item.price + item.shipping + item.fees
premium = landed / oz_pure / spot[item.metal] - 1
score   = w.premium*(1-premium) + w.liquidity*liq(item) \
        + w.dealer*rep(item.dealer) + w.numis*grade_bonus(item)
